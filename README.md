# Luciano Gebler — Site Profissional Pessoal

Repositório-fonte do site profissional pessoal:

**lucianogebler.com.br**

## Objetivo

Este site tem como objetivo funcionar como portfólio profissional pessoal, com foco em desenvolvimento de software, análise de dados, análise aplicada, sistemas de apoio à decisão e tecnologias digitais relacionadas.

O portfólio representa uma iniciativa profissional independente e pretende apoiar uma nova etapa de atuação construída sobre a experiência anteriormente adquirida em agronomia, pesquisa científica, avaliação ambiental, agricultura de precisão e agricultura digital.

## Escopo

O site poderá incluir:

- softwares e ferramentas computacionais desenvolvidos de forma independente;
- projetos de análise de dados;
- modelos e sistemas de apoio à decisão;
- demonstrações técnicas e estudos de caso;
- documentação e downloads de software;
- links para repositórios de código-fonte e GitHub Releases;
- informações selecionadas sobre a trajetória profissional;
- links para perfis institucionais e acadêmicos externos.

Trabalhos institucionais e materiais desenvolvidos no âmbito da Embrapa não serão reproduzidos ou redistribuídos por meio deste site. Quando forem relevantes para contextualizar a trajetória profissional, poderão ser referenciados por meio das fontes institucionais externas apropriadas.

## Idiomas

O site será projetado desde o início para suporte multilíngue, inicialmente nos seguintes idiomas:

- Português
- Inglês
- Espanhol
- Italiano

O português será utilizado como idioma principal de desenvolvimento, documentação interna e manutenção do projeto.

## Arquitetura inicial

- **Domínio:** lucianogebler.com.br
- **Controle de versão:** Git e GitHub
- **Hospedagem inicial:** GitHub Pages
- **Distribuição de software:** GitHub Releases
- **Métricas de utilização:** web analytics e estatísticas agregadas de downloads
- **Identificação de usuários:** voluntária, quando pertinente
- **Aplicações futuras:** serviços externos, APIs e infraestrutura de back-end poderão ser integrados conforme a necessidade

A arquitetura deverá permanecer portável, permitindo que os serviços de hospedagem sejam alterados futuramente sem modificar a identidade profissional do site ou seu domínio principal.
